# Open Chat

Message any number on WhatsApp without saving it to your contacts.
Type a number (Israel +972 is the default), tap **Start chat**, and WhatsApp opens on that number.

A single static `index.html` with no build step. Built by T.B.Technologies Inc.

## Mail → WhatsApp bridge

Need to send WhatsApp messages from a program that can only send email? Run the bridge for free on Google Apps Script with [`apps-script/`](apps-script/README.md), or on your own server with [`mail-bridge/`](mail-bridge/README.md).
