# WhatsApp Express

A single-page tool to message any WhatsApp number without saving it to your contacts.

- Pick a country code, type the number (or paste a full `+...` international number)
- Optionally pre-fill a message
- Open the chat directly, or copy the `wa.me` link
- Recent numbers are remembered locally in your browser

## Usage

Open `index.html` in a browser, or host it on any static host (e.g. GitHub Pages:
Settings → Pages → deploy from branch, root folder).
