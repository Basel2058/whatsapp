    How it works

    1. Pick the country code and type the number (leading zeros are removed automatically).
    2. Optionally write a message.
    3. Tap Open chat — WhatsApp opens straight into a conversation with that number.

    Everything runs in your browser. Recent numbers are only stored on this device.
